Lesson 02 / 25 · 15 menit

HTTP Methods: GET, POST, PUT, DELETE

HTTP method memberitahu server aksi apa yang diminta browser. Memahami method memudahkanmu membaca request di Burp Suite.

Bayangkan toko online

Melihat daftar barang adalah GET. Membuat pesanan baru biasanya POST. Memperbarui data dapat menggunakan PUT atau PATCH. Menghapus alamat dapat menggunakan DELETE. Server tetap wajib memeriksa hak akses pada setiap operasi.

Contoh request

GET /api/orders/101 HTTP/1.1
Host: lab.vulnlab.local
Accept: application/json
Authorization: Bearer <dummy-token>

Method HTTP sendiri tidak memberikan hak akses. Meski memakai GET, server harus memastikan pesanan tersebut memang boleh dibaca oleh pengguna yang login.

Cek pemahaman

Jika user B mengganti ID pesanan milik user A lalu bisa membacanya, masalah utamanya adalah...

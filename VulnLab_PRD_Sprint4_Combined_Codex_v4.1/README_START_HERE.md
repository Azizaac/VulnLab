# VulnLab — Sprint 4 Combined handoff

This package **extends your current V4 repository**. Do not create a new project.

## How to use with Codex

1. Extract the ZIP.
2. Copy `PRD_SPRINT4_COMBINED.md` and `CODEX_SPRINT4_COMBINED.md` into the root of your existing VulnLab repository. If you extracted the entire archive, use the files from its top level; the `V4_REFERENCE/` folder contains a copy of the existing V4 baseline for reference.
3. Confirm your existing repository contains `MASTER_PRD.md`, `design/visual-reference.png` and running app code. Do NOT replace your working project with the baseline in `V4_REFERENCE/`.
4. Open `CODEX_SPRINT4_COMBINED.md` and paste its instructions into Codex. Ask it to read `PRD_SPRINT4_COMBINED.md`.
5. Review `docs/SPRINT4_PROGRESS.md` and the actual tests/screenshots when Codex finishes.

## Scope

Progress analytics, streak, XP, achievements, practice vulnerability reports, validation/toast UX, integration testing. aaPanel deployment is deferred until after Sprint 5 QA.

## Important distinction

This is **a complete requirements specification and implementation prompt for Sprint 4**, not prebuilt PHP/React feature code. It does not establish that Sprint 3 labs or Sprint 4 tests have already passed.

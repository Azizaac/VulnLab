## Editorial state model
- `research_draft_unreviewed`: AI-assisted original educational prose, citations present, **not fact-checked by an independent expert**. This is the state of the seeded content in this bundle.
- `review_in_progress`: an identified editor has opened a revision task.
- `reviewed`: human has checked conceptual accuracy, reference links, examples and licensing, and populated `reviewed_at`, `reviewer_id`, `source_version`.
- `published`: editor explicitly approves it for general release. Do not automatically mark seeded drafts as published to the public. Local personal preview may show drafts with a badge.

## Every publishing review must verify
1. Official links load and match relevant claims; recheck versions, including OWASP 2023 API risk list and WSTG stable vs latest.
2. Concepts and examples are technically correct and beginner-accessible.
3. Quizzes have exactly one defensible correct answer and useful wrong-answer explanations.
4. Lab intentionally vulnerable code has documented scope, isolation and secure solution.
5. Text/visuals are original; reuse any licensed assets only when attribution and license conditions are satisfied.
6. `updated_at`, `reviewed_at`, reviewer, and changelog set honestly.
7. If a primary source is temporarily unavailable, do not replace it with a made-up citation.

Source license caution: OWASP materials may have CC BY-SA or project-specific notices; PortSwigger content must be linked and not wholesale copied. MDN documentation has its own licenses. Do not assume all assets can be redistributed.
